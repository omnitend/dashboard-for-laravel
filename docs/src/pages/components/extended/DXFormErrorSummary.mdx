# DXFormErrorSummary

Lists everything the last failed submit of a `useForm` returned: the server's
message, then one row per validation message with a readable label
("Price (line 1): Must be positive."). Place it next to the submit control.

[DXForm](/components/extended/DXForm) renders one for you, directly above its
submit button (its `errorSummary` prop). Use this component on its own when
the submit control is outside the form, such as a modal footer; see
[A summary outside the form](/components/extended/DXForm#a-summary-outside-the-form).

- It reads `form.submitFailure`, so it renders nothing before a failure,
  keeps listing every message while the user edits, and disappears when the
  next submit starts or one succeeds.
- Rows follow tab order, then field order; keys no visible field owns
  (unrendered keys, hidden fields) come last as plain text.
- A row is left without its "Label: " prefix when the message already names
  the field, and keeps it when the message holds a raw key (`delivery_date`)
  or two rows share a message.
- A row naming a visible field is a button that emits `select-target`.
- It is one `DAlert` (danger, the subtle tint) with `role="alert"`, remounted
  per failure so each new failure is announced once.

```vue
<DXFormErrorSummary
  :form="form" :fields="fields" :tabs="tabs"
  :targets="formRef?.errorTargets ?? null"
  @select-target="formRef?.focusErrorTarget($event)"
/>
```

The resolver behind it is exported too: `resolveErrorTargets(errors, { fields,
tabs, model, isFieldVisible, isTabVisible, resolveLabel })` returns one
`ErrorTarget` (`errorKey`, `messages`, `lines`, `fieldKey`, `tabKey`, `label`)
per key, for building your own display.
