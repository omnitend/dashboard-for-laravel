# DXSaveButton

A save button that confirms the save in place. While saving it shows
[DButton](/components/base/DButton)'s busy state; once saved it changes to a
disabled **✓ Saved** (tick, same colour as before: a disabled button is
normally grey, but this one keeps its own variant at full strength, so only
the label and the disabled state change); when the form changes it goes back
to the normal Save button.

[DXForm](/components/extended/DXForm) uses it for its submit button and works
out `saving` and `saved` itself. For a form you build yourself, drive it with
two booleans: set `saving` while the request runs, set `saved` when it
succeeds, and clear `saved` whenever the data changes.

```vue
<DXSaveButton type="submit" :saving="isSaving" :saved="isSaved">Save</DXSaveButton>
```

## Accessibility

- The button is a polite live region (`aria-live="polite"`), so the change to
  "Saved" is announced. While saving it is `aria-busy`, which holds
  announcements until the save settles.
- The saved state uses the real `disabled` attribute, not just a style.
- The saved state keeps full contrast rather than Bootstrap's faded disabled
  look, because it reports an outcome rather than an unavailable action.
