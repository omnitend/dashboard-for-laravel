# DXDashboardNavbar

A responsive top navigation bar component for Laravel dashboards with user menu, search functionality, and sidebar toggle.

## Live Examples

<ComponentExample
  client:load
  code={`<script setup>
import { ref } from 'vue';
import {
  DXDashboardNavbar,
  DDropdownItem,
  DDropdownDivider
} from '@omnitend/dashboard-for-laravel';

const currentUser = ref({
  name: 'Sarah Johnson',
  email: 'sarah@example.com',
});

const pageTitle = ref('Dashboard Overview');

const handleToggle = () => {
  console.log('Sidebar toggle clicked');
};

const handleLogout = () => {
  console.log('Logout clicked');
};
</script>

<template>
  <DXDashboardNavbar
    :user="currentUser"
    :page-title="pageTitle"
    @toggle-sidebar="handleToggle"
  >
    <template #search>
      <input
        type="text"
        class="form-control form-control-sm"
        placeholder="Search..."
      />
    </template>

    <template #user-menu-items="{ user }">

        Profile

        Settings

      <DDropdownDivider />
      <DDropdownItem @click="handleLogout">

      </DDropdownItem>
    </template>
  </DXDashboardNavbar>
</template>`}

**Height note:** the bar is exactly `--dx-dashboard-header-height` tall (64px
by default), the same token that sizes the sidebar header, so their bottom
edges line up. To make the shell's header shorter or taller, override that one
property; never size the navbar and the sidebar header separately. Single-row
content must fit `--dx-navbar-content-height` (the header height minus the
bar's padding and border); default-size buttons and inputs do. Taller content
(e.g. `btn-lg`, or a tall custom `user-menu` slot) makes the bar grow, so it no
longer lines up with the sidebar header.

**On phones** the bar is one row: the toggle, the search filling the middle,
and the user menu. Page actions take a row below unless `actionsOnMobile` is
`hide`. A shortcut hint in a `<kbd>` inside the search is hidden when the
search is narrower than 16rem; slot content can query the `dx-navbar-search`
container for anything else (for example a shorter placeholder, which CSS
cannot change, so swap it with a container query on two elements or in
script).

## Extended Component

This is a custom component that extends beyond simple Bootstrap Vue Next wrappers,
providing additional functionality specific to Laravel dashboards.

## Features

- **Responsive Design**: Adapts to different screen sizes with mobile-friendly layout
- **User Avatar**: Automatically generates avatar with user initials
- **Flexible Search**: Customisable search slot for your search implementation
- **Sticky Positioning**: Stays at the top of the page when scrolling
- **Customisable Slots**: Multiple slots for complete customisation of layout and functionality
