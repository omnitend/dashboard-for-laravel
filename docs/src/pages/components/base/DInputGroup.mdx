# DInputGroup

Type-safe wrapper around Bootstrap Vue Next BInputGroup component. Easily extend form controls by adding text, buttons, or button groups.

## On narrow screens

An input group never wraps an affix away from its input: a search box and its
button, a "£" amount, or "@" and a username stay one joined control at every
width.

Below md (768px), a group with **two or more controls** wraps instead, so a
filter bar's group cannot run off a phone screen. A leading text label takes
its own row, and the controls sit beneath it as separate controls, each with
its own corners and a small gap. From md up the group is joined as usual. Text
and buttons do not count as controls, so `[−] [input] [+]` stays joined.

```vue
<DInputGroup prepend="Date range" class="w-auto">
  <DFormInput type="date" />
  <DFormInput type="date" />
</DInputGroup>
```

CSS cannot tell a label from an affix, so a group whose text is part of a
sentence wraps too: "Every" in `Every [1] [days]` would take its own row, as
would "£" in `£ [cost] ex. VAT per [unit]`. Set `wrap="never"` to keep such a
group joined at every width. It adds the `dx-input-group--joined` class, which
also works on plain `.input-group` markup. The default is `wrap="narrow"`.

```vue
<DInputGroup prepend="Every" wrap="never" class="w-auto">
  <DFormInput type="number" v-model="interval" />
  <DFormSelect v-model="unit" :options="['days', 'weeks', 'months']" />
</DInputGroup>

<!-- Plain markup -->
<div class="input-group dx-input-group--joined">
  <span class="input-group-text">£</span>
  <input class="form-control" type="number" />
  <span class="input-group-text">ex. VAT per</span>
  <select class="form-select">…</select>
</div>
```
