# DToaster

DToaster - A type-safe wrapper around Bootstrap Vue Next's BToaster component. Container for managing and displaying multiple toast notifications with configurable positioning.

## Showing a toast with `useToast()`

Call `useToast()` in any component inside `<DApp>`, and `create()` a toast.
Mount `DApp` once at your app's root: it provides what `useToast()` needs
and renders the toasts, so you don't need a `DToaster` as well.

```vue
<DApp>
  <App />
</DApp>
```

With no `modelValue` a toast shows for 5 seconds; a number is the duration in
milliseconds, `true` keeps it until closed, and `false` creates it hidden
(call `.show()` on what `create()` returns). Hovering a toast pauses its
countdown. Toasts show at the bottom right unless you pass `position` (for
example `'top-end'`), and each is removed once it has hidden unless you pass
`{ keep: true }` as the second argument.
