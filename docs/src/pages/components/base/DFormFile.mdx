# DFormFile

DFormFile - A type-safe wrapper around Bootstrap Vue Next's BFormFile component. A file picker with a Browse button, the chosen file name, and a drag-and-drop zone, styled like the theme's text inputs (same height, border, focus ring and crimson invalid state). `v-model` is a `File` for a single file, a `File[]` with `multiple` (or `directory`), and `null` when nothing is chosen.

Use it instead of hand-building a `btn` label around a hidden `<input type="file">`. The Browse button is a real `<button>`, so it is in the Tab order and opens the picker on Enter or Space; give the component an `id` and pass the same value to `DFormGroup`'s `label-for` to label it.

## Methods

Through a template ref: `reset()` clears the selection and sets the model to `null` (setting `v-model` to `null` does the same), `focus()` and `blur()` act on the Browse button.
